# Уточнение идеи

Пакет-скилл. Жёстко и критично уточняет сырую идею: один конкретный вопрос за ход, от двух до
четырёх готовых вариантов, рекомендация с причиной. Ответы становятся карточками графа.

В пакете два файла по существу: `skill.md` — инструкция агенту, `__init__.py` — манифест.
Чтобы изменить поведение, правьте `skill.md` и перезапустите оболочку.

## Установка

```
pip install -e .
```

Нужны `ideagraph-core` и `ideagraph-shell`.

## Тесты

```
pip install pytest
python -m pytest
```
